# تصاميم تطبيق العيادة (للعرض على العميل)

افتح `index.html` لعرض كل التصاميم، أو `01-sakina/index.html` لشاشات التصميم الأول.

## الهيكل

```
designs/
  index.html            ← صفحة اختيار التصميم
  shared/               ← مشترك بين كل التصاميم (لا يتغير)
    icons.js            ← الأيقونات
    present.js          ← شريط التنقل بين الشاشات + قائمة الشاشات العشر
    gallery.css/.js     ← صفحات المعرض
  01-sakina/            ← التصميم 1 «سكينة» (style.css هنا هو الأساس: التخطيط + هويته)
  02-waqar/             ← التصميم 2 «وقار»
  03-dafa/              ← التصميم 3 «دفء»
    style.css           ← يستورد تخطيط 01 ثم يعيد تعريف الهوية (ألوان، خط، زوايا، أشكال)
    01…10-*.html        ← الشاشات العشر (نسخة مطابقة في كل تصميم)
```

> أي إصلاح في التخطيط داخل `01-sakina/style.css` ينعكس على التصاميم الثلاثة.

## إضافة تصميم جديد

1. انسخ ملفات HTML من `01-sakina` إلى مجلد جديد (مثل `04-xxx`).
2. اكتب `style.css` يبدأ بـ `@import url("../01-sakina/style.css");` ثم يعيد تعريف المتغيرات والمكونات. لا تغيّر محتوى HTML حتى تبقى المقارنة عادلة.
3. حدّث العنوان والوصف ولوحة الألوان في `index.html` الخاص بالتصميم.
4. أضف سطرًا للتصميم في مصفوفة `DESIGNS` داخل `designs/index.html`.

## أثناء العرض

- الأسهم: ← التالي، → السابق. مفتاح H يخفي شريط التنقل.
- شاشة «حجز موعد» تفاعلية: اختيار اليوم والوقت، ثم المراجعة، ثم الإرسال.
- شاشة «مواعيدي» فيها تبويبان: القادمة والسابقة.
